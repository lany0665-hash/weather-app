# 🌤️ 기상청 날씨 기반 옷차림 추천 & 천체관측 적합도 예보

기상청 공개 API를 활용하여 실시간 날씨 데이터를 분석하고, 체감온도에 맞춰 옷차림을 추천해주며, 2주간의 천체관측 적합도를 예측하는 웹 애플리케이션입니다.

초보자 및 중학교 과학 수업 실습을 위해 **파이썬 표준 라이브러리만 사용**하여 구현되었으며, 외부 프레임워크나 CDN 라이브러리에 의존하지 않습니다.

---

## 🚀 주요 기능

### 1. **오늘의 날씨 & 옷차림 추천**
- 기상청 초단기실황 API를 통해 실시간 관측 데이터 수집
- 어제 이맘때, 지금, 내일 아침 9시의 세 시점 비교
- 기온, 습도, 풍속을 고려한 **간이 체감온도** 계산
  - **겨울철** (기온 ≤ 10℃, 풍속 ≥ 1.3m/s): Wind Chill 공식
  - **여름철** (기온 ≥ 25℃): 열지수(Heat Index) 공식
- 체감온도 구간별 8가지 옷차림 추천
- 강수 형태 및 확률에 따른 우산 안내

### 2. **2주 천체관측 적합도 예보** ⭐ NEW
- 기상청 단기예보 API를 통해 14일간 예보 데이터 수집
- 천체관측에 영향을 미치는 요인 분석:
  - ☁️ 하늘 상태 (맑음/구름많음/흐림)
  - 💧 습도 (낮을수록 좋음)
  - 💨 풍속 (약할수록 좋음)
  - 🌧️ 강수 형태 및 확률
- 각 날씨 조건에 따라 **0~100점 평가**
- 간편한 별(⭐) 표시로 적합도 표현

### 3. **과학 교육용 설계**
- 관측(실황) 데이터와 예보 데이터의 차이 학습
- API 원본 데이터 표시 (학습용 Monospace 폰트)
- 체감온도 계산 원리 설명
- 추천 규칙 테이블로 의사결정 과정 시각화

## 🔧 설치 및 실행

### 1. 저장소 클론
```bash
git clone https://github.com/lany0665-hash/weather-app.git
cd weather-app
```

### 2. 기상청 API 인증키 설정

#### 인증키 발급:
1. [기상청 API허브](https://apihub.kma.go.kr) 방문
2. 회원가입 후 로그인
3. **오픈API** → **전체 API** → **동네예보** 검색
4. **"활용신청"** 클릭하여 승인 요청
5. 승인 후 **"앱키"** 복사

#### 인증키 등록:
프로젝트 루트 디렉토리에 `key.txt` 파일 생성 후 인증키 입력:

```
YOUR_API_KEY_HERE
```

> **TIP**: 인증키가 없어도 앱은 실행되지만, Mock 데이터로 동작합니다.

### 3. 서버 실행

**Windows:**
```bash
python app.py
```

**macOS / Linux:**
```bash
python3 app.py
```

### 4. 브라우저에서 접속
```
http://localhost:8000
```

## 🌐 API 엔드포인트

### `/api/weather`
현재 날씨 및 옷차림 추천 데이터 반환

**요청:**
```
GET /api/weather?nx=98&ny=76
```

**응답 예시:**
```json
{
  "now": {
    "T1H": 27.2,
    "REH": 62.0,
    "WSD": 2.8,
    "PTY": "0",
    "kind": "관측"
  },
  "mock": false
}
```

**요청:**
```

```

```json
{
  "success": true,
  "data": [
    {
      "date": "2026-08-29",
      "temp": 25.3,
      "humidity": 65.0,
      "wind_speed": 2.1,
      "sky": "1",
      "stargazing_score": 85,
      "stargazing_recommendation": "매우 좋음 ⭐⭐⭐"
    }
  ]
}
```

## 🧮 계산 원리

### 체감온도 (Apparent Temperature)

#### 겨울철 (기온 ≤ 10℃, 풍속 ≥ 1.3m/s)
Wind Chill 공식:
```
WC = 13.12 + (0.6215 × T) - (11.37 × V^0.16) + (0.3965 × V^0.16 × T)
```
- T: 기온 (℃)
- V: 풍속 (km/h)

#### 여름철 (기온 ≥ 25℃)
Heat Index 간이식:
```
HI = T + (H - 60) × 0.05
```
- T: 기온 (℃)
- H: 습도 (%)

#### 표준 조건 (10℃ < T < 25℃)
기온 그대로 사용

### 천체관측 적합도 점수

각 조건별 점수 산정:
- **강수** 있음: -50점
- **구름** (흐림/구름많음): -20 ~ -40점
- **습도** (높을수록): -15 ~ -30점
- **풍속** (강할수록): -10 ~ -20점
- **극단 온도**: -5점

**등급 판정:**
| 점수 | 추천도 | 표시 |
|------|--------|------|
| 80+ | 매우 좋음 | ⭐⭐⭐ |
| 60-79 | 좋음 | ⭐⭐ |
| 40-59 | 보통 | ⭐ |
| 0-39 | 좋지 않음 | ✗ |

## ⚠️ 주의사항

### 1. API 인증키
- 인증키는 **절대 공개하지 마세요**
- `key.txt`는 `.gitignore`에 포함되어 있습니다
- GitHub에 커밋되지 않습니다

### 2. 기상청 API 제한
- 분당 최대 10회 호출 제한
- 분당 용량 1MB 제한 (Starter 기본값)
- 필요시 활용신청 후 등급 상향 가능

### 3. 데이터 정확도
- 모든 데이터는 **교육용**입니다
- 실제 외출 결정 시 기상청 공식 예보 확인 권장
- 천체관측 적합도는 **참고용**이며, 실제 관측 시 추가 요소 고려 필요

### 4. 위치 설정
기본값: 부산 (nx=98, ny=76)

다른 지역 좌표는 [기상청 격자 좌표 조회](https://www.kma.go.kr) 참고
